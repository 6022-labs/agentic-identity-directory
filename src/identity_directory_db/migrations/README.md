# Database migrations

Postgres migrations for the identity directory database, generated by [Atlas](https://atlasgo.io) from the gorm models in `schema/models.go` and applied at startup by [goose](https://github.com/pressly/goose).

## New migration

Add the model to `schema/models.go`, then:

```bash
./src/identity_directory_db/migrations/generate_migrations.sh <name>
```

Atlas starts a throwaway Postgres in Docker, diffs it against the models and writes `postgres/<timestamp>_<name>.sql` plus `atlas.sum`.

## Editing a migration

Only edit a migration no environment has applied yet, then run `atlas migrate hash --dir file://postgres` from this folder.
